# Tarik Campara — Portfolio Website

A responsive, dark-themed static portfolio designed for forward deployed engineering, solutions engineering, and cloud engineering roles.

## How to view

Open `index.html` in any browser. No install, compilation, framework, or API keys required. The Google Fonts stylesheet needs internet access; system fallbacks work offline.

## Before you publish

1. Open `script.js` and edit `CONTACT.email`, `CONTACT.linkedin`, and `CONTACT.github` with your real details. Until configured, clicking these controls displays an explanation rather than opening a misleading link.
2. Review every accomplishment for accuracy. The project **DeployOps** is intentionally labeled **in development**, and its UI is a **concept preview**. Update the project section as you actually implement and test capabilities.
3. Optionally replace the hero wording, role preferences, and the list of technologies as your experience evolves.
4. Change the `<title>`, meta description, and Open Graph information in `index.html` if desired.

## Hosting options

- **GitHub Pages:** Create a public repository, upload the 4 website files, then Settings → Pages → Deploy from a branch → main / root.
- **Netlify:** Drag and drop the folder at https://app.netlify.com/drop.
- **Vercel:** Import a repository; for this static site you don't need a build command.

## Structure

- `index.html` — content and semantic structure.
- `styles.css` — palette, responsive layout, components, micro-interactions.
- `script.js` — mobile menu, reveal effects, configurable contact buttons.
- `favicon.svg` — vector TC icon.

## Editing colors

Colors are in `styles.css` under `:root`. Main variables: `--bg`, `--panel`, `--blue`, `--text`, and `--muted`.

## Project integrity

DeployOps is planned/in-progress as of October 2026. Do not portray mock dashboard numbers or unbuilt features as production achievements. Once deployed, replace concept copy with a link to the real repository, live demo, tested features, and concrete engineering outcomes.
